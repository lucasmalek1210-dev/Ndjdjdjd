# Elton John Interactive Discography

All 34 of Elton John's studio albums (1969–2025), plus soundtracks, live albums and greatest-hits collections, with tracklists and songwriter credits checked against Wikipedia.

A static, no-build web page: open `index.html` in a browser or upload this folder to any host (GitHub Pages, Netlify, etc.).

- **Hover** an album: the cover tilts and the record slides out.
- **Click** an album: opens its tracklist. ★ marks tracks with a story.
- **Click a song**: shows album, year, writers, producer, a short note, and a Listen link (YouTube search). Prev/Next buttons and ↑/↓ keys move between tracks; Esc closes.
- **Shelves**: albums are grouped into Studio, Soundtracks & Musicals, Live and Greatest Hits. The type buttons show one shelf at a time.
- **Originally on**: songs on live and hits albums link back to the studio album they first appeared on, and reuse that song's story.
- **Search** finds albums *or* songs (e.g. "rocket"). Decade chips filter the grid.
- Deep links: `index.html#gybr` opens that album directly.

## Editing the data
Studio albums live in `data.js`; soundtracks, live and hits albums in `data-extras.js` (set `type` to `soundtrack`, `live` or `compilation`). A track is either `"Title"` or `["Title", "note", "writers override", "originally on"]`.

### Real album covers
Covers are generated by default. To use real artwork you have rights to, put the image in `covers/` and add `cover: "covers/file.jpg"` to that album.

## Files
- `index.html`: page structure
- `style.css`: styles and animations
- `app.js`: interactivity
- `data.js`: studio albums, tracklists and song notes
- `data-extras.js`: soundtracks, live albums and greatest hits
